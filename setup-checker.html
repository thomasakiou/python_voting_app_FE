4. Setup Instructions

🚀 Quick Setup Steps:
  1. Create Admin User: If no admin exists, you may need to create one through your backend
  2. Upload Voters: Use the admin panel to upload your voters.csv file
  3. Create Offices: Add voting offices (e.g., President, Governor, etc.)
  4. Add Candidates: Create candidates for each office
  5. Test Voting: Use the concurrent voting test once setup is complete

5. Manual Backend Commands

If you have direct backend access, you can create test data manually: 
# Create admin user (if using Django/Python backend)
python manage.py createsuperuser
